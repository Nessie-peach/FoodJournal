## iOS App 接入要点速记

1. **统一走 OpenAI 兼容协议**：四家均支持 `POST {Base URL}/chat/completions` + `Authorization: Bearer <Key>`，可直接复用 OpenAI SDK / 自封装客户端。
2. **火山方舟 Key 体系陷阱**：Agent Plan 专属 Key ≠ 方舟常规 Key；Base URL 与 Key 类型必须匹配（Agent Plan Key + `/api/plan/v3`），否则 401。
3. **模型 ID 写法陷阱**：火山 Agent Plan 用点号无日期写法（`doubao-seed-2.0-mini`），按量 `/api/v3` 用连字符带日期写法（`doubao-seed-2-0-mini-260428`）——同一模型两种 ID，取决于端点。
4. **DeepSeek 旧模型名已弃用**：`deepseek-chat`/`deepseek-reasoner` 已于 2026-07-24 弃用，新接入直接用 `deepseek-v4-flash`/`deepseek-v4-pro`。
5. **百炼地域绑定**：API Key 与 endpoint 地域必须一致（北京 Key 调新加坡 endpoint 会 401）。
